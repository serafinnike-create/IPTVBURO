# IPTV BURO — Android Mobile

Aplicação dedicada a celulares e tablets Android.

Escopo planejado:

- interface touch própria;
- catálogo, perfis e progresso compatíveis com os contratos compartilhados;
- Media3 para reprodução;
- BURO Offline Vault conforme o GDD 6.0;
- armazenamento privado;
- testes e CI próprios.

A aplicação Android TV atual não deve ser apresentada como versão mobile final. Regras portáveis devem ser extraídas sem regredir o build existente.
